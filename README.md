🎲 Number Guessing Game (Java Console App)

A fun Java console game where the player guesses a random number between 1 and 100 with limited chances.

✅ Features

* Random number generated between 1–100
* 10 chances to guess correctly
* Hints: "Too high" or "Too low"
* Option to play multiple rounds

🛠 How to Run

```bash
javac NumberGame.java
java NumberGame
```

📤 Sample Output

```
Welcome to Random Number Guess Game!  
Enter your guess number between 1 and 100  
You have only 10 chances to win the Game  
Enter your guess: 45  
Too high try again!  
...  
Congratulation! Your guess is correct and Your Score is 4  
Do you want to play again (Yes/No):
```

📝 Note

* Case-sensitive response for "Yes/No"
* No input validation (e.g., entering letters or out-of-range numbers)
